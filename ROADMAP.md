## Button Devices

- Introduce a new physical device with type `myhome.firmware.sensor.Button`
- Properties:
  - `pressed: boolean` — raw physical state, published directly by hardware
  - `action: string` — high-level gesture (`single`, `double`, `long`, etc.), **may be generated by the driver**
    - Action is derived based on pause duration and timing between raw `pressed/released` events

**Example:**

```json
{
  "physical_device": "ESP_bg_kitchen",
  "driver": "nodemcu-java-driver",
  "alias": "btn1",
  "title": "Kitchen Button",
  "type": "myhome.firmware.sensor.Button",
  "version": 1,
  "supported_commands": [],
  "properties": {
    "pressed": {
      "value": false,
      "changedAt": "2025-08-06T19:45:03.100Z"
    },
    "action": {
      "value": "double",
      "changedAt": "2025-08-06T19:45:03.500Z"
    }
  },
  "enabled": true
}
```
